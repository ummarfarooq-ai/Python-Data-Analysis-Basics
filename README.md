# Python Data Analysis Basics

This repository contains beginner-friendly Python scripts for performing basic data analysis tasks.  
The goal of this project is to demonstrate simple techniques used in data processing, analysis, and visualization.

## Features

- Data cleaning using Pandas
- Basic statistical analysis
- Simple data visualization using Matplotlib

## Project Files

data_cleaning.py – Handles missing values and duplicate rows  
data_analysis.py – Performs basic statistical analysis  
visualization.py – Creates simple data visualizations

## Technologies Used

- Python
- Pandas
- Matplotlib

## Installation

1. Clone the repository

git clone https://github.com/yourusername/Python-Data-Analysis-Basics.git

2. Install dependencies

pip install pandas matplotlib

3. Run scripts

python data_cleaning.py

## Purpose

This project was created as part of learning Python for data analysis and building a practical GitHub portfolio.
